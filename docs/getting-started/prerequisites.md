1. **Benchling App with Admin Privileges**: Liminal builds on top of Benchling's LIMS system. You will need to have a Benchling App with admin privileges to your Benchling tenant(s). Liminal needs admin privileges in order to manipulate Benchling schemas through the Benchling API and SDK. Ensure the app is configured as an admin on all your entity schemas and dropdowns. [Follow instructions here](https://docs.benchling.com/docs/getting-started-benchling-apps#installing-your-app) to install a Benchling App with admin privileges.

2. **Python**: Liminal supports Python versions 3.10 through 3.13 for package users.

### Notes

- Liminal currently supports coverage for Benchling entity schemas, results schemas, and dropdowns at the moment.
